# বিডি ল্যান্ড প্রো (BDLandPro) - অটোমেটিক ক্লাউড APK বিল্ড নির্দেশিকা

আপনার লোকাল কম্পিউটারে কোনো ভারী Android SDK, Android Studio বা Flutter ইনস্টল করার প্রয়োজন **নেই**! সম্পূর্ণ অ্যাপ্লিকেশনটি ক্লাউডে GitHub Actions-এর মাধ্যমে সম্পূর্ণ স্বয়ংক্রিয়ভাবে কম্পাইল হয়ে রেডি-টু-ইউজ `.apk` ফাইলে রূপান্তরিত হবে।

---

## 🚀 মাত্র ৩টি সহজ ধাপে আপনার ফোনের জন্য `.apk` ডাউনলোড করুন:

### ধাপ ১: GitHub রিপোজিটরিতে কোড পুশ করা
রিপোজিটরির রিমোট অরিজিন সেট করে `main` ব্রাঞ্চে কোড পুশ করুন:
```bash
git add .
git commit -m "feat: implement all 24 land survey tools and fix CI/CD apk build"
git push -u origin main
```

---

### ধাপ ২: GitHub Actions বিল্ড পর্যবেক্ষণ
১. কোড পুশ করার পর GitHub রিপোজিটরির **Actions** ট্যাবে যান (`https://github.com/saidor98/BDland/actions`)।
২. আপনি দেখতে পাবেন **`Build Android APK`** নামের অটোমেটিক ওয়ার্কফ্লো রান হচ্ছে।
৩. এটি ক্লাউডের উবুন্টু সার্ভারে জাভা ১৭ এবং ফ্ল্যাটার পরিবেশ প্রস্তুত করে অ্যান্ড্রয়েড প্ল্যাটফর্ম স্কাফোল্ডিং তৈরি করবে, সমস্ত ইউনিট টেস্ট চালাবে এবং রিলিজ এপিকে কম্পাইল করবে (সাধারণত ২ থেকে ৩ মিনিট সময় লাগে)।
৪. বিল্ড সফলভাবে সম্পন্ন হলে একটি সবুজ টিকচিহ্ন (Green Checkmark ✅) প্রদর্শিত হবে।

---

### ধাপ ৩: সরাসরি `.apk` ডাউনলোড ও ফোনে ইনস্টল
১. সফল বিল্ড রানটির ওপর ক্লিক করে ভেতরে প্রবেশ করুন।
২. স্ক্রিনের নিচের দিকে **Artifacts** সেকশনে যান।
৩. সেখানে **`BDLandPro-Release-APK`** নামের ফাইল দেখতে পাবেন। এটিতে ক্লিক করে ডাউনলোড করুন।
৪. ডাউনলোডকৃত জিপ ফাইলের ভেতর আপনি পাবেন **`app-release.apk`**।
৫. আপনার অ্যান্ড্রয়েড ফোনে ফাইলটি ট্রান্সফার করে ইনস্টল করুন এবং নির্ভুলভাবে জমি পরিমাপ, খতিয়ানের হিস্যা ও ফারায়েজ বণ্টন শুরু করুন!

## 🛠️ ২৪টি সম্পূর্ণ কার্যকর ও আনলকড টুলস:
১. **গুগল ম্যাপে জমি পরিমাপ**: স্যাটেলাইট ম্যাপে প্লট এঁকে রিয়েলটাইম ক্ষেত্রফল ও পরিধি পরিমাপ
২. **মৌজা ম্যাপ পরিমাপ (সহজ)**: ১৬", ৩২", ৬৪" গান্টার স্কেল ক্যালিব্রেশন এবং লিংক ও ফুটে সরাসরি পরিমাপ
৩. **মৌজা ম্যাপ পরিমাপ (অ্যাডভান্স)**: CAD-মানের পরিমাপ, স্ন্যাপিং ও AutoCAD DXF এক্সপোর্ট
৪. **AnyShape Divider**: যেকোনো অনিয়মিত বহুভুজকে নির্দিষ্ট শতক অনুপাতে বিভাজন
৫. **চতুর্ভুজ পরিমাপ ও বণ্টন (QuadMaster)**: ৪ বাহু ও কর্ণ দিয়ে হিরন বনাম গড় পদ্ধতির তুলনা ও বণ্টন
৬. **সকল মৌজা ম্যাপ**: ৮টি বিভাগের সকল জেলা ও উপজেলার জেএল সূচিপত্র ও নকশা ভিউয়ার
৭. **গুগল ম্যাপে মৌজা ম্যাপ**: স্যাটেলাইট মানচিত্রে মৌজা ম্যাপ সুপারইম্পোজ এবং KML/KMZ এক্সপোর্ট
৮. **তুলনামূলক প্যান্টোগ্রাফ**: সিএস/এসএ এবং আরএস/বিএস ম্যাপ পাশাপাশি বা ওভারলে রেখে সীমানা পরিবর্তন বিশ্লেষণ
৯. **ম্যাপ জয়েন্ট**: একাধিক সংলগ্ন মৌজা ম্যাপ শিট জোড়া দিয়ে একীভূত নকশা তৈরি
১০. **জমি পরিমাপ (মাল্টি-শেপ)**: ত্রিভুজ, ট্রাপিজিয়াম, বৃত্ত, উপবৃত্ত, সামান্তরিক ইত্যাদি জ্যামিতিক পরিমাপ
১১. **আনা-গণ্ডা কনভার্টার**: প্রথাগত আনা-গণ্ডা-কড়া-ক্রান্তি-তিল এবং দশমিকের দ্বিমুখী রূপান্তর
১২. **Map Converter**: স্ক্যান করা নকশার থ্রেশহোল্ড কন্ট্রাস্ট ক্লিন ও ভেক্টর প্রসেসিং
১৩. **ক্ষেত্রফল/অজানা বাহু**: নির্দিষ্ট ক্ষেত্রফল বজায় রেখে অনুপস্থিত বাহু বা সীমানা নির্ণয়
১৪. **শতক-কাঠা-বিঘা-একর রূপান্তর**: কাস্টম কাঠা সাইজসহ ১৮+ একক কনভার্সন
১৫. **অনুপাত ক্যালকুলেটর**: অংশীদারদের মাঝে রাস্তার সম্মুখ সীমানা (Frontage) বজায় রেখে জমি বণ্টন
১৬. **দাগের অংশ**: খতিয়ানের হিস্যা অনুযায়ী নির্দিষ্ট দাগে নিজের অংশের জমি বের করা
১৭. **খতিয়ান বিশ্লেষণ**: সিএস, এসএ, আরএস, বিএস খতিয়ান অডিট এবং ১৬ আনা বা ১.০০০০০ হিস্যা যাচাই
১৮. **উত্তরাধিকার (মুসলিম - ফারায়েজ)**: সুন্নি হানাফী নিয়মে আসহাবে ফুরুজ, আসাবা, আওল ও রদসহ বণ্টন
১৯. **উত্তরাধিকার (হিন্দু)**: দায়ভাগ আইন অনুসারে হিন্দু উত্তরাধিকার বণ্টন
২০. **হিস্যা ক্যালকুলেটর**: খতিয়ান ও দলিলের অংশ ভগ্নাংশের যোগ-বিয়োগ-গুণ-ভাগ
২১. **তফসিল বণ্টন**: নির্ভুল চৌহদ্দি ও তপশিলনামা তৈরির রেজিস্ট্রি ফরম্যাট
২২. **প্রিন্ট স্টুডিও**: দাগের নকশা সাজিয়ে A4 সাইজের প্রিন্ট ও PDF সার্টিফিকেট তৈরি
২৩. **জমির সকল সূত্র**: গান্টার চেইন, নামজারি প্রক্রিয়া, খাজনা ও সার্ভে সূত্রের রেফারেন্স গাইড
২৪. **সার্ভেয়ার মেমো**: ক্লায়েন্ট ভাউচার, খরচ, অগ্রিম ও বকেয়া হিসাবের ডিজিটাল লেজার
